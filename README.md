# TechStore — контрольная работа №2

**Тема:** «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

TechStore — учебный интернет-магазин смартфонов Apple, Samsung и Xiaomi. Проект демонстрирует работу с Bootstrap 5, адаптивной сеткой, готовыми компонентами, собственными стилями и JavaScript-функциями.

## Технологии

- HTML5 — структура четырёх страниц.
- Bootstrap 5.3.6 — локально подключённый CSS-фреймворк.
- CSS3 — индивидуальные стили в `css/custom.css`.
- JavaScript — поиск, фильтрация, сортировка, избранное, корзина и проверка формы.
- `localStorage` — сохранение корзины и избранного в браузере.

## Страницы

- `index.html` — главная, преимущества, популярные товары, модальное окно и FAQ.
- `catalog.html` — каталог, поиск, фильтры, ценовой ползунок и сортировка.
- `product.html` — описание, характеристики, похожие модели и добавление товара в корзину. Модель задаётся параметром `?id=`.
- `order.html` — корзина, управление количеством, удаление позиции, промокод и форма заявки.

## Подключение Bootstrap

Bootstrap подключён **локально, без CDN**. На каждой HTML-странице в `<head>` сначала загружается `vendor/bootstrap/css/bootstrap.min.css`, затем `css/custom.css`. Перед закрывающим `</body>` подключается `vendor/bootstrap/js/bootstrap.bundle.min.js`.

В папке `vendor/bootstrap/` находится Bootstrap 5.3.6. Стили и интерактивные компоненты Bootstrap не требуют интернет-соединения. Собственный `custom.css` подключён после Bootstrap, чтобы переопределять отдельные визуальные параметры, не переписывая фреймворк.

## Реализованные компоненты Bootstrap

- `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `g-*` — адаптивная сетка.
- `navbar`, `navbar-expand-lg`, `navbar-toggler`, `collapse` — навигация и мобильное меню.
- `card`, `card-body` — карточки смартфонов.
- `btn`, `btn-primary`, `btn-outline-*` — кнопки.
- `badge` — метки товаров.
- `alert` — сообщения и информационные уведомления.
- `modal` — модальное окно на главной странице.
- `form-control`, `form-select`, `input-group`, `form-check`, `form-label` — форма заявки.
- `accordion` — блок часто задаваемых вопросов.
- `toast` — уведомления о действиях пользователя.

## Самостоятельные доработки

- Поиск товаров по названию, бренду, описанию и памяти.
- Фильтрация по бренду и максимальной цене.
- Ценовой ползунок находится в обычном потоке страницы. У панели фильтров нет `position: fixed` или `position: sticky`, поэтому она не должна смещаться при прокрутке.
- Быстрые подборки «До 40 000 ₽» и «Флагманы».
- Сортировка по популярности, цене и названию.
- Избранное с сохранением в `localStorage`.
- Корзина с сохранением, изменением количества и удалением товаров.
- Автоматический подсчёт стоимости и промокод `TECH10` (демонстрационная скидка 10%).
- Отдельная страница товара с характеристиками и похожими моделями.
- Проверка обязательных полей формы и состояния согласия.
- Адаптивная компоновка для телефона, планшета и компьютера.
- Состояния пустого каталога и пустой корзины.

## Проверка

1. Распаковать папку проекта и открыть её в Visual Studio Code.
2. Запустить `index.html` через Live Server (или открыть страницу в браузере).
3. Перейти по всем четырём пунктам навигации.
4. В каталоге проверить поиск, бренды, ползунок цены, быстрые подборки и сортировку.
5. Добавить несколько смартфонов в корзину и обновить страницу — содержимое должно сохраниться.
6. Изменить количество, удалить позицию и проверить пересчёт суммы.
7. Проверить мобильное меню, модальное окно и FAQ-аккордеон.
8. Изменить ширину браузера и проверить адаптивную сетку.
9. На странице заказа попробовать отправить пустую форму, затем заполнить обязательные поля.

## Ограничения демонстрации

Это фронтенд-проект. Корзина и избранное сохраняются только в браузере. Форма проверяет обязательные поля, но не передаёт персональные данные на сервер. База данных, авторизация, реальная оплата и серверная обработка заказов не реализованы: методические указания к КР №2 требуют интерфейс сайта и форму заявки, а не backend.
